# 实现逻辑

先有html的结构层，然后用css控制页面的样貌，还要通过Javascript来实现里面关系的计算。

---

```
输入要兑换的币额
    ↓
程序计算另一种代币值
    ↓
页面显示代币值
    ↓
点击swap,验证后通过兑换
    ↓
清空两个输入框
    ↓
弹出成功提示
```
